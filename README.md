# 魔方小高手 🧊

给一个 5 岁、已经能 1 分钟左右还原（七步法）的孩子做的**个人专属 CFOP 进阶训练网页**。

重点不是背公式，而是把高手的底层思维变成孩子能玩的关卡：

| 岛 | 练什么 | 核心思想 |
| --- | --- | --- |
| 🏝️ 魔方的秘密 | 方块、开门关门、找朋友、让路 | 看方块不看贴纸；R U R' 只动顶层；A B A' |
| 🌳 好朋友回家 | F2L 4 把万能钥匙 + 难情况变简单 | 不背 41 个公式，所有情况先变成 4 种基础情况 |
| 🔍 侦探眼睛 | 15 秒观察、边做边看 | 慢而不停比快而停顿更快 |
| 🏰 顶层城堡 | 两步 OLL + 两步 PLL | 从"重复做到好"升级到"认出来就做对" |

另外有 5 个小游戏（跟踪小侦探、快找好朋友、F2L 练习场、车灯快认、乌龟节拍器）、带 15 秒观察的计时器、可以输入任何公式看动画的"自由魔方"，以及家长中心（12 周课表、每日 15 分钟安排、进度和成绩统计）。

## 使用

```bash
npm install
npm run dev      # 本地打开 http://localhost:5173
npm test         # 验证所有公式和 F2L 情况描述
npm run build    # 生成 dist/
```

推送到 `main` 后，GitHub Actions 会自动部署到 GitHub Pages（需要在仓库 Settings → Pages 里把 Source 设为 "GitHub Actions"）。平板上打开后可以"添加到主屏幕"，像 App 一样用。

## 结构

- `src/cube/model.ts` 魔方状态模型（26 个小方块的位置和朝向）
- `src/cube/alg.ts` 公式解析、求逆、给孩子的口令
- `src/cube/view.ts` three.js 3D 魔方：动画、转动箭头、点选方块、高亮
- `src/content/algs.ts` 所有公式（每条都有测试验证）
- `src/content/lessons.ts` 课程内容（场景：讲解 / 看动画 / 动手 / 点一点 / 选择题 / 真魔方）
- `src/pages/` 各个页面（`book.ts` 是公式本：家里的叫法 + 会不会打分）

颜色约定：白色底、黄色顶，默认绿色朝前（家长中心可以改成红色等其它颜色朝前）。电脑上可以用键盘转魔方（R、Shift+R、Alt+U）。训练记录保存在浏览器 localStorage。
